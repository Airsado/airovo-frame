# 表单系统重构计划

> **目标：** 对标 vben-admin 的表单体系，将 `@airovo/forms` 从简单的 JSON-schema 渲染器升级为完整的表单框架。

**当前状态：** `useAForm(schema)` + `<AForm>` 只有基础的字段渲染，缺少组件映射、依赖联动、布局控制、内置操作按钮等能力。

**vben 对标点：** `FormApi` class + `componentMap` 渲染模式 + `dependencies` 联动 + `grid-cols` 布局 + 内置 `submit/reset` 按钮 + `collapsible` 折叠

---

## Task 1: 定义新类型体系

**文件：** 重写 `packages/core/forms/src/types.ts`

**目标：** 从 vben 的类型体系中取核心部分，去掉 airovo 不需要的多 UI 库适配层。

核心类型：

```ts
// 字段渲染组件类型（框架内置映射）
type BuiltInComponent = 'Input' | 'Password' | 'Number' | 'Email' | 'Textarea' | 'Select' | 'Switch' | 'DatePicker'

// 组件映射表
type ComponentMap = Record<BuiltInComponent, Component>

// 字段依赖配置
interface FieldDependencies {
  triggerFields: string[]           // 监听哪些字段变化
  componentProps?: (values, api) => Record<string, any>  // 动态 props
  disabled?: (values, api) => boolean
  hidden?: (values, api) => boolean
  required?: (values, api) => boolean
}

// 单个字段 schema
interface FormField {
  fieldName: string
  label?: string
  component: BuiltInComponent | Component  // 内置名字或自定义组件
  componentProps?: Record<string, any>
  defaultValue?: any
  rules?: ZodTypeAny
  description?: string
  dependencies?: FieldDependencies
  hidden?: boolean
  disabled?: boolean
  required?: boolean
}

// 表单配置
interface FormProps {
  schema: FormField[]
  validation?: ZodTypeAny          // 全局 zod schema（和字段级 rules 二选一）
  layout?: 'horizontal' | 'vertical'
  wrapperClass?: string            // grid 布局，如 'grid-cols-1' / 'grid-cols-2'
  collapsible?: boolean
  collapsedRows?: number           // 折叠时保留行数，默认 1
  showDefaultActions?: boolean     // 是否显示内置提交/重置按钮
  submitButtonText?: string
  resetButtonText?: string
  handleSubmit?: (values) => Promise<void> | void
  handleReset?: (values) => Promise<void> | void
}
```

## Task 2: 创建 FormApi 类

**文件：** 新建 `packages/core/forms/src/form-api.ts`

**目标：** 从 vben 的 `FormApi` class 精简，保留核心能力。

```ts
class FormApi {
  form: FormContext           // vee-validate 的 form context
  state: FormProps            // 当前表单配置

  // 挂载（组件 onMounted 时调用）
  mount(form: FormContext, schema: FormField[]): void

  // 获取值（支持 valueFormat 转换）
  getValues<T>(): T

  // 设置值（过滤非 schema 字段）
  setValues(fields: Record<string, any>): void

  // 更新单个字段值
  setFieldValue(name: string, value: any): void

  // 重置
  resetForm(): void

  // 校验
  validate(): Promise<{ valid: boolean; errors: Record<string, any> }>

  // 提交（校验 + 调用 handleSubmit）
  submitForm(e?: Event): Promise<void>

  // 动态更新 schema（增删字段）
  updateSchema(updates: Partial<FormField>[]): void
  removeSchemaByFields(fields: string[]): void
}
```

## Task 3: 重写 AForm.vue 渲染层

**文件：** 重写 `packages/core/forms/src/AForm.vue`

**目标：** 基于 `componentMap` 动态渲染字段，支持依赖联动。

核心改动：

1. **ComponentMap 默认映射：**
```ts
const DEFAULT_COMPONENT_MAP = {
  Input, Password: Input, Number: Input, Email: Input,
  Textarea, Select, Switch, DatePicker,
}
```

2. **依赖联动：** watch `triggerFields` 的值变化，调用 `dependencies` 中的函数更新 `componentProps` / `disabled` / `hidden`

3. **Grid 布局：** `<div :class="wrapperClass">` 包裹所有字段

4. **内置操作按钮：**
```html
<div v-if="showDefaultActions" class="flex gap-2 justify-end pt-4">
  <Button @click="handleReset">重置</Button>
  <Button type="submit">提交</Button>
</div>
```

5. **折叠支持：** `collapsible` 时超出 `collapsedRows` 的字段默认 `hidden`，底部显示"展开/收起"按钮

## Task 4: 简化 useAForm 组合式函数

**文件：** 重写 `packages/core/forms/src/index.ts` 中的 `useAForm`

**目标：** 去掉 `AFormBindings` 的冗余层，直接暴露 `FormApi` + `handleSubmit`。

```ts
export function useAForm(options: FormProps) {
  const api = new FormApi(options)
  const { handleSubmit, ...formContext } = useForm({ ... })

  onMounted(() => api.mount(formContext, options.schema))

  return {
    api,           // FormApi 实例
    values,        // reactive values
    errors,        // reactive errors
    handleSubmit,  // vee-validate 的 handleSubmit
    isSubmitting,
    isValid,
  }
}
```

应用层用法：
```ts
const { api, values, handleSubmit } = useAForm({
  schema: [{ fieldName: 'username', label: '用户名', component: 'Input' }],
  handleSubmit: async (data) => { await login(data) },
})
```

## 不与 vben 对齐的部分（有意简化）

- **不引入 multi-UI-framework 适配** — vben 的 componentMap 支持 antd/element/naive 多套 UI。airovo 只有 shadcn，不需要
- **不引入 FormApi.merge()** — vben 的多表单合并场景不适用
- **不引入 fieldMappingTime / arrayToStringFields** — 日期映射和数组字段转换暂时不需要
- **不引入 field array** — vben 的 VbenFormFieldArray（动态行）暂不实现

---

## 风险

- `vee-validate` 的 `FormContext` 类型可能与新 API 不完全兼容，需要用 `as` 断言
- `watch` 依赖联动可能触发循环更新，需加 `immediate: false` + 防抖
- 现有 demo 页面（AFormDemo.vue）使用旧 API，需同步更新
